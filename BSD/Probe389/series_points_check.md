## 6. PARI/GP 仲裁闭环（2026-10-12）

**环境**：WSL Ubuntu-22.04 内 PARI/GP 2.13.3（`apt pari-gp`）。`ellms` 不存在（2.14+），用底层 `msfromell(E,1)` + `mseval(M,v,[0,1;c,d])`。

**方法（三步）**：
1. **H₁ 求值**：`mseval(M, v, [0,1;c,d])` = 真模符号 H₁ 值 f_H₁({0,r})（r=c/d 非尖点端点）。端点 (c:d)↔c/d；`[1,0;0,1]`={∞,0}、`[1,0;1,2]`={∞,1/2} 等探测确认。
2. **扩展换算**：f_eclib({∞,r}) = f_H₁({0,r}) − f_H₁({0,∞}) = f_H₁({0,r}) + 1/5（f_H₁({0,∞}) = −1/5 由锚 M(0)=1/5 反推）。**锚验证**：0→1/5 ✓、1/2→−4/5 ✓、1/3→−3/10 ✓、1/9→−4/5 ✓（全命中 docstring）。
3. **尖点端点补**：分子 c ≡ 0 mod 11 的端点（11/27、22/27）是 Γ₀(11)-尖点，mseval 给调和积分特殊值（{0,11/27}=4/5 破坏 M⁺ 对称 M(1−r)=M(r)，S=[[−1,1],[0,−1]]∈Γ₀(11)），强制用对称 f(1−r)=f(r) 补。

**自洽性**（分布恒等式 a_p·f({0,r}) = Σ_m f({0,(r+m)/p}) + f({0,pr})）：
- r=1/9：−1·(−1) = 1 = 1 + (−1) + 3/2 + (−1/2) ✓
- r=1/27：−1·1 = −1 = 1/2 + (−3/2) + 1 + (−1) ✓（含 {0,1/81}=1/2 实测）

**重算（read_pari_recompute.py，结构 = debug_trace_series.py，仅替换求值源）**：
- Σ_j s_j = **1283 mod 3⁷ → 68 mod 243 = Sage T⁰ 精确命中** ✓
- s_j = [1138, 1138, 385, 999, 999, 385, 1138, 1138, 524]
- 11/27 对称补（−13/10）⟹ μ=1286；若用 PARI 尖点特殊值（4/5→1）⟹ μ=2181 ⟹ Σ=234 ≠ 68，**反证尖点补必要性**。

**根因裁决**：矛盾三角形 **分支 (a)** 成立——真模符号 = H₁（2 维）泛函 + 常数校正 1/5；我的 λ = 3 维商线性泛函（无常数项）。两者在锚点及 1/3ᵏ 型点一致（λ(1/27)=6/5 ✓），一般点分叉：λ(4/27)=11/5 vs 真 6/5、λ(26/27)=−4/5 vs 真 6/5、λ(2/9)=−3/10 vs 真 17/10。**λ 的锚拟合/Hecke 链/反射全自洽，但扩展约定 ≠ eclib**；series 数值必须用真模符号（PARI 管道），λ 仅保留用于链层论证。
