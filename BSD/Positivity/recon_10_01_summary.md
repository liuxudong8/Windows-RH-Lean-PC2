## 1. 根数约束（采样判据）

ε(E⁵) = ε(E)·χ₅(N)。翻转奇偶需要 χ₅(N) = −1 ⟺ **N ≡ ±2 (mod 5)**：

- 秩 1 曲线（ε = −1）且 N ≡ ±2 → ε⁵ = +1（偶秩）→ 大概率秩 0 → **(1,0)**；
- 秩 0 曲线（ε = +1）且 N ≡ ±2 → ε⁵ = −1（奇秩）→ 大概率秩 1 → **(0,1)**。

## 3. 数学意义（排除层正性的分量结构）

Leibniz 一阶（Artin 分解，ExclusionReduction §1 真定理）：

- **(1,0)**：L′(E/K,1) = L′(E,1)·L(E⁵,1)（因 L(E,1) = 0）。
  正性 = **秩 1 BSD 正性（猜想分量）× 秩 0 BSD 正性（定理分量**，Kolyvagin–Logachev））。
- **(0,1)**：L′(E/K,1) = L(E,1)·L′(E⁵,1)（因 L(E⁵,1) = 0）。
  正性 = **秩 0 BSD 正性（定理）× 秩 1 BSD 正性（猜想）**。

**对比 (1,1) 型**（秩 2 P* 分支）：需要**两个猜想分量**（L′(E,1)>0 且 L′(E⁵,1)>0，纠缠同号）。
排除层的 (1,0)/(0,1) 型只需**一个猜想分量 + 一个定理分量**——排除层正性比 (1,1) 分支弱一档，
这是"秩 1 反向在排除层上更可及"的精确含义。
