## 4. P* 的理论收口（对"正性下界"问题的精确答案）

三型判别（Leibniz 展开，Artin 分解）：

- **(2,0)**：L″(E/K,1) = L″(E)·L(E⁵)——需 秩2 BSD 正性（L″(E)>0，猜想）× 秩0 L(E⁵)>0（定理）。实例：389a1/K，L″(E/K,1) ≈ 13.53 > 0。
- **(1,1)**：L″(E/K,1)/2 = L′(E)·L′(E⁵)——**非真空**（6/6 存在）。纠缠正性在数据上全成立，但其证明**等价于秩 1 的 BSD 正性**（L′(1) = Ω·R·Sha·T⁻²·c⁺ > 0 对所有秩 1 曲线——一般情形未被证明）。
- **(0,2)**：(2,0) 的镜像（E ↔ E⁵）。

**结论（边界声明）**：
1. P*（秩恰 2 ⟹ L″(E/K,1) > 0）⟺ **分量级 BSD 正性**（秩 0 分量是定理，秩 1/秩 2 分量是猜想）。P* **不比 BSD 正性更弱，也不比它更强**——它不是独立可证定理，而是 BSD 正性的重述。
2. 用户原提法"所有秩 ≥ 2 的曲线 L″ 有正下界"严格为假（秩 3 的 5077a1/K：L″ = 0；秩 4 的 (2,2)/(0,2)-高秩配置：L″ = 0）。**秩恰 2 是唯一可辩护口径**。
3. 根数在 K=ℚ(√5) 下的真实约束：ε(E⁵) = ε(E)·χ₅(N) 只钉奇偶——它把 (1,1) 候选精确钉在"N ≡ ±1 (mod 5) 的秩 1 曲线"上，而这一族**非空且密度可观**（6/6 采样全中）。根数约束因此**不能用来排除 (1,1)**——(1,1) 是 K 独有、必然要面对的分支。
