# 2　文献核实：Yildirim 方法的结构与 GRH 依赖定位

## 2.1　Yildirim 1991（manuscripta math 72, 325-334）全文要点

方法：对模 q 的两个字符 χ_1、χ_2，定义跨族配对相关 G_{χ1,χ2}(x,T)=2πΣ_{0<γ1,γ2≤T}x^{i(γ1−γ2)}w(γ1−γ2)（w(u)=4/(4+u²)）。Theorem 1：Σ_{χ1,χ2}χ̄_1(a)χ_2(a)G_{χ1,χ2}(x,T)∼φ(q)Tlogx（T 范围 x/q·logx≤T≤e^{x^{1/4}}，q≤x^{1/2}log⁻³x）——**跨所有字符对平均**。证明机制（公式 (6)-(8)）：(i) Landau 型显式公式 Σ'_{n≤x}Λ(n)χ(n)/n^r = Σ_ℓ x^{−(2ℓ+r+a)}/(2ℓ+r+a) − Σ_ρ x^{ρ−r}/(ρ−r) − (L′/L)(r,χ)——**对 L(s,χ) 无条件成立**（零点对称和、含平凡项）；(ii) 积分形式（公式 (7)）：(2σ−1)Σ_ρ x^{iγ}/((σ−1/2)²+(t−γ)²) = −x^{−1/2}[素数加权和] + x^{1/2−σ+it}(logqτ+O(1)) + O(x^{−1/2−a}τ^{−1})——GRH 下对所有 x≥1 有效；(iii) 配对和经 Montgomery–Vaughan 均值定理 ∫₀^T|Σa_n n^{−it}|²dt = TΣ|a_n|²+O(·) 展开。**GRH 依赖定位**：仅出现在 (ii) 的「对所有 x≥1 有效」与跨模平均的 PNT——因 Theorem 1 的 q 随 x 增长，需 GRH-PNT；固定模（q=5 固定）时该需求消失。

## 2.2　Murty–Zaharescu 2002：Selberg 类 GRH-free 显式公式

Forum Math. 14, 65-83 全文要点：对 F,G∈Selberg 类，Theorem 2：ℱ_{F,G}(α)=(1/d_F·x·logT)Σ_{n=1}^∞Λ_F(n,x)Λ_G(n,x)+O(T^{−δ1})（x=T^{αd_F}，Λ_F(n,x)=Λ_F(n)(n/x)^{1/2}（n≤x）/·(n/x)^{3/2}（n>x））——**GRH-free**；Theorem 4：Σ_{−T≤γF,γG≤T}f(ρF+ρG)=(T/π)Σ_{n≥2}Λ_F(n)Λ_G(n)g(n)+O(·)（g∈C_c¹、supp g⊂(2,∞)、f 为 g 的 Mellin 变换）。推论：弱配对相关猜想（GRH-free 版：ℱ_{F,G}(α)=δ_{F,G}α+o(1)，0<α<c_{F,G}）⟺ Selberg 正交性猜想。**含义**：配对和的显式公式（零点侧 ↔ 素数幂加权侧）在 Selberg 类内无条件存在——L(s,χ_5)（模 5 实特征、原始函数）属此框架——**显式公式层不存在存在性缺口**。

## 2.3　BGS 2306.04799：核技巧与弱实部假设

ζ 版无条件 Montgomery 定理的关键组件：(i) 核构造（引理 5：supp r⊂[−1,1] 的核形式——与 L 无关、可共用，对应 λ≤1/2 域，恰为 S6 的 C_MT 框架）；(ii) 弱实部假设（|β−1/2|<1/(2logT)，对 T^{3/8}<γ≤T——比 RH 弱得多、非临界线假设）；(iii) 配对和的展开（对角主项 + 素数项 + 离线误差）。结论形态：在弱假设下，至少 61.7% 简单——方法既不要求也不提供临界线信息。

# 3　闭路判定：移植路线与三层结构

闭路判定：(H2) 可闭路——存在明确的构造路线，把 L(s,χ_5) 单族配对相关显式公式建成 BGS 型。三层结构：

## 3.1　显式公式层（Yildirim (6)/(7) 的 L 版——无条件）

Landau 型显式公式（Yildirim 公式 (6)）对 L(s,χ_5) 无条件成立（零点对称和 + 素数加权和 + 平凡项——无 GRH 依赖）；配对和的积分展开（公式 (7) 的机制）在弱实部假设下成立（离线零点 β>1/2 的贡献由 |β−1/2|≤1/(2logT) 控制——BGS 同款）。差型配对（γ−γ'）经复共轭不变性转和型（γ+(−γ')，零点集关于实轴对称）——与 Murty–Zaharescu 的和型显式公式衔接。

## 3.2　素数项层（Siegel–Walfisz 替代 GRH-PNT——移植优于原方法）

配对和展开的非对角项（素数项）形如 Σ_{p}Λ(p)χ_5(p)p^{−1/2}K̂(δlogp)（核频域窄支撑 → 只p 接近 1 有贡献）。固定模 5 的 Siegel–Walfisz：|Σ_{n≤x}Λ(n)χ_5(n)|≤c·x·e^{−c′√logx}（无条件、子指数）——点态、无 GRH 依赖。**这是移植的关键改善**：Yildirim 的 Theorem 1 需 GRH 仅因跨模平均（q 随 x 增长）；我们固定 χ_5，SW 完全足够——素数项层无条件、子指数可忽略。

## 3.3　核层与弱假设（BGS 引理 5 直接复用）

核构造（supp r⊂[−1,1]）、配对和展开形式、离线误差处理（弱实部假设 + T^{3/8} 切割）均为 BGS 机制的直接移植——与 L 的结构无关（核分析部分共用），只替换显式公式与素数定理的 L 版本。

# 4　定理 S7.1（构造骨架）

定理 S7.1（L(s,χ_5) 单族 BGS 型配对公式——骨架）：设弱实部假设（BGS 同款）：T^{3/8}<γ≤T 的零点满足 |β−1/2|<1/(2logT)。则对 λ≤1/2 核族（BGS 引理 5 形式、K̂ 支撑窄、K(0)=1），L(s,χ_5) 单族配对常数满足：A_L(K) = C_MT + O(ε) + o(1)——即 A_L(K) ≤ C_MT+O(ε)+o(1)，C_MT=1/2+(1/√2)cot(1/√2)=1.3274992963（S6 框架）。

证明路线（骨架）：(i) 配对和经复共轭对称转和型，Landau 显式公式（Yildirim (6)）展开 → 对角主项 N_L（K̂(0)=1）+ 素数项 ΣΛ(p)χ_5(p)p^{−1/2}K̂(δlogp) + 平凡项 + 离线项；(ii) 素数项：Siegel–Walfisz（模 5）+ 分部求和 → O(e^{−c√logT})（子指数）；(iii) 离线项：弱实部假设 + T^{3/8} 切割（BGS 引理机制）→ o(1)；(iv) 核逼近：C_MT 最优核 f₀（S6）的 ε 正则化（Lamzouri η_ε）→ 配对常数偏差 O(ε)。取 ε=10⁻²：A_L ≤ 1.3375+o(1)。

## 4.1　推论 S7.2（0.6725 严格化最终形态）

在定理 S7.1 + XLI 分解口径（ζ 族由 XLI/Lamzouri+BGS 无条件）下：并集在线比例 =(N_ζ(2−A_ζ)+N_L(2−A_L))/N_K ≥ 2−(C_MT+O(ε))−o(1) = 0.6725−O(10⁻²)−o(1)——**0.6725 严格化在弱假设下完全无条件成立**（S6 理论侧 + S7 闭路侧；数值侧余量 0.11，S6 §3.5）。
