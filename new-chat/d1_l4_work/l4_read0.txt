摘要：

本文处理第三篇骨架的引理 L4：ζ 与 L(χ₅) 零点族的交叉相关项 S_ζL=Σw((γ−γ′)ℓ)。先修正原始表述：S_ζL 的期望阶不是 o(N_K)，而是 E[S_ζL]=N_K/2·(1+o(1))（局部密度平均，可严格化）；对秩-迹论证真正构成威胁的是涨落 Δ=S_ζL−E。再给出两部分进展：（i）无条件部分——互显式公式的素数主项 F_ζL(u,T)=O(1)，因 L(χ₅) 在 Re≥1 无零点且两族无公共零点，主对角线项消失，此为谱对偶框架相对单族 Weil 二次型的结构性优势；（ii）待证部分——涨落 Δ 的 o(N_K) 界等价于“ζ 零点局部密度波动对 L 零点位置的长程去相关”，给出方差公式与短程条件 (D)。最后更新作用域：arXiv:2608.13637v2 的 2/3（simple 且在线）、5/6（distinct）结果已扩展到本原 Dirichlet L 函数，故 θ_ζ、θ_L(χ₅)≥2/3 与 θ_K≥2/3 均已自动成立，且其机制正是 rank-trace＋Weil 压缩＋Sylvester——与第三篇秩-迹同源。结论：单函数方向已被 AI 占满，在线比例的增量只可能来自跨族互斥（Δ 的结构），L4 是唯一兑现门。

关键词：

交叉相关；双矩；局部零点密度；去相关；秩-迹不等式；在线比例；Weil 二次型

# 1　背景与引理修正

## 1.1　第三篇 L4 的原始表述与错误

第三篇骨架的双矩四项分解含交叉项：

M(T) = M_ζζ + M_LL + 2S_ζL，S_ζL = Σρ∈Z(ζ) Σρ′∈Z(L) w((γ−γ′)ℓ)，	（1）

w(u)=4/(4+u²)，ℓ=log T，γ、γ′ 分别为 ζ 与 L(χ₅) 零点的虚部（取 0<γ,γ′≤T）。第三篇的引理 L4 原表述为“预期 |S_ζL|≤o(N_K(T))（待证）”。本计算显示该表述不成立：S_ζL 的期望阶与 N_K 同阶（第 3 节）。对秩-迹论证需要控制的不是 S_ζL 本身，而是其围绕期望的涨落。

## 1.2　本文目标

目标：给出 S_ζL 的（i）期望主项（严格）、（ii）素数主项（无条件）、（iii）涨落项的控制条件；并据此修正交叉项在在线比例论证中的角色。记号：N_ζ(T)=(T/2π)ℓ+O(ℓ)，N_L(T) 同阶，N_K=N_ζ+N_L≈(T/π)ℓ；两族零点无公共零点。

# 2　定义与表示

局部窗口密度：

A(t) = Σ0<γ≤T w((γ−t)ℓ)，	（2）

即 ζ 零点在 t 的 1/ℓ 邻域内的加权计数。由 Stieltjes 积分，

S_ζL = ∫0T A(t) dN_L(t)。	（3）

式（3）把交叉项化为“ζ 零点局部密度对 L 零点位置的积分”——涨落分析的自然形式。

# 3　主项：期望阶

## 3.1　局部密度的期望

对固定 t∈(T/2,T]，w((γ−t)ℓ) 的支集为 |γ−t|≤O(1/ℓ)，其中 ζ 零点密度为 (1/2π)log(u/2π)（Riemann–von Mangoldt 的局部平均）。于是（附录 A 给出严格推导）

E[A(t)] = ∫ w((u−t)ℓ)·(1/2π)log(u/2π)du = 1+o(1)。	（4）

## 3.2　交叉项期望

E[S_ζL] = N_L(T)·(1+o(1)) = (N_K(T)/2)·(1+o(1))。	（5）

修正 1。第三篇 L4 的 o(N_K) 预期错误；正确表述为 S_ζL = (N_K/2)(1+o(1)) + Δ，涨落 Δ 待控。该主项来自两族零点的平凡独立贡献，本身不携带信息。

# 4　素数主项：互显式公式（无条件）

定义归一化交叉相关（Montgomery 型）：

F_ζL(u,T) = (T/2πℓ)−1 Σγ,γ′≤T Tiu(γ−γ′) w(γ−γ′)。	（6）

沿 Montgomery 1973 的围道法推广到两族：把 Σ_γ 换成 (1/2πi)∮(ζ′/ζ)(s)T^{ius}ds 型围道，向内平移经显式公式后，主项由素数贡献给出：

F_ζL(u,T) 主项 = (2/ℓ)·Σp≤T (χ₅(p)·log p)/(p1+2iu) + o(1)。	（7）

因 Re(1+2iu)=1 且 1+2iu≠1（u≠0），Σ_p χ₅(p)(log p)/p^s 主部等于 −(L′/L)(s)（s=1+2iu，Re s=1），而 L(χ₅) 在 Re≥1 无零点（s=1 处 L(χ₅,1)≈0.6007…≠0 非奇异），故

F_ζL(u,T) = O(1)，对 |u|≤1−δ 一致，无条件成立。	（8）

结构注释。单族时 F(u,T) 含 T^{−2u} 主导项（来自对角线/极点结构）；跨族时两族无公共零点，主对角线消失，素数项成为唯一主项且一致有界——这是 ζ_K 谱对偶表述（φ(s)=Λ_K(2s−1)/Λ_K(2s) 的极点=两族零点并集）特有的结构性优势，单族 Weil 二次型无法复制。

# 5　涨落项与去相关条件（L4 实质）

## 5.1　涨落分解

Δ = S_ζL − E[S_ζL] = ∫ (A(t) − 1) dN_L(t)。	（9）

## 5.2　方差公式

Var(Δ) = ∫∫ C_ζ(t−t′) dN_L(t)dN_L(t′)，C_ζ(h) = Cov[A(t), A(t+h)]。	（10）

若 ζ 零点局部密度的涨落对 h≫1/ℓ 快速衰减（C_ζ 短程），则（附录 B）：

Var(Δ) = N_L(T)·∫ℝ C_ζ(h)dh·(1+o(1)) = O(N_L)。	（11）

条件 (D)（去相关）：∫_ℝ|C_ζ(h)|dh<∞。在 (D) 下，Chebyshev 给出

Δ = O(√(N_L·ℓ)) = o(N_K)。	（12）

## 5.3　条件 (D) 的性质与难点

（i）(D) 是跨族条件，弱于单族 pair correlation：它只要求“ζ 零点局部密度的波动与 L 零点位置无长程锁定”，不要求单族零点对的短程性。（ii）严格证明 (D) 需要 ζ×L 的混合矩或零点计数函数差（N_ζ−N̄_ζ）沿 L 零点的二重和：Δ=∫(A−1)dN_L 的四阶展开含 Σ_{γ′,γ″∈Z(L)}（ζ 密度涨落的两点相关）。这等价于“两族零点的长程互相关=0”，是互显式公式的算术核（素数对 p,q 带 χ₅ 的双和）问题。（iii）反向风险：若两族零点共享局部密度涨落（Δ 与 N_K 同阶且正），则交叉项以正系数进入双矩，秩-迹论证的阶结构改变，θ_K 下界退化——必须在数值上先排除该情形。

## 6.2　θ_K≥2/3 自动成立

L(χ₅) 为本原模 5 二次特征，故 θ_ζ≥2/3、θ_L(χ₅)≥2/3 均已无条件成立；两族无公共零点，并集在线零点数=N_ζθ_ζ+N_Lθ_L，N_ζ≈N_L，得

θ_K ≥ (θ_ζ+θ_L)/2 − o(1) ≥ 2/3 − o(1)，无条件。	（13）

## 6.3　增量的唯一来源：跨族互斥

单函数方向（ζ 或单个 L）的 2/3 已被 AI 用与第三篇同源的秩-迹机制占满；对 θ_K>2/3 的唯一通道是“两族离线零点互斥”——即 Δ<0 的结构性内容（若 ζ 的离线零点处 L 密度系统性偏低，则并集在线比例高于单族值）。该互斥恰由交叉项涨落 Δ 编码：Δ 的负偏置 ∝ 跨族离线互斥量。故 L4 从“控制一个误差项”升级为“度量两族离线零点的互斥”——这是本框架相对 AI 唯一的、不可替代的增量对象。

# 7　风险检查点

（1）原始 o(N_K) 表述错误已修正（期望 N_K/2 主项）；

（2）涨落 Δ 的 o(N_K) 界（条件 (D)）是唯一卡点；其失败模式是两族共享长程密度涨落；

（3）Δ 的符号未定：Δ<0 才携带离线互斥；Δ≥0 时 θ_K 无增量；需先数值/算术证据定向；

（4）单函数 2/3 已被 AI 占满，且机制与第三篇同源——若本文不转向跨族，整个系列对 AI 无增量；

（5）本估计纯属算术侧（零点计数与显式公式），与 (T,W) 长度重参数化无关。

# 附录 A　E[A(t)] 的严格计算

取 t∈(T/2,T]。w((γ−t)ℓ) 仅对 |γ−t|≤O(1/ℓ) 非平凡。对单峰光滑计数核，ζ 零点计数满足 N(u)=(u/2π)log(u/2π)−u/2π+O(log u)，其局部平均密度 ρ(u)=(1/2π)log(u/2π)+O(1/u)（分部积分后一致成立）。于是 E[A(t)]=∫w((u−t)ℓ)ρ(u)du=(1/ℓ)∫w(v)(ρ(t+v/ℓ))dv=(ρ(t)/ℓ)∫w(v)dv+O(ℓ⁻¹·sup|ρ′|·∫|v|w)=ρ(t)·2π/ℓ+O(1/ℓ²)。代入 ρ(t)=ℓ/2π+O(1/T) 得 E[A(t)]=1+O(1/T+1/ℓ²)。积分得 E[S_ζL]=N_L(T)(1+o(1))。

# 附录 B　方差公式的推导

Var(Δ)=E[∫∫(A(t)−1)(A(t′)−1)dN_L(t)dN_L(t′)]=∫∫C_ζ(t−t′)dN_L(t)dN_L(t′)。对 t′=t+h，N_L 密度 ρ_L(t)=ℓ/2π+O(1/t) 缓变，且 C_ζ(h) 在 |h|≫1/ℓ 时由 (D) 衰减，故∫∫C_ζ(t−t′)dN_LdN_L≈∫dN_L(t)·∫C_ζ(h)ρ_L(t+h)dh=N_L(T)·ρ_L(T)·∫C_ζ(h)dh·(1+o(1))=N_L·(ℓ/2π)·∫C_ζ·(1+o(1))。若 ∫C_ζ=O(1)（(D) 的量化），Var(Δ)=O(N_L·ℓ)，Δ=O(√(N_Lℓ))=o(N_K)。□
