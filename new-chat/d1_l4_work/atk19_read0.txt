# 攻防 XIX：并集素项净压制与显式公式余项数值级

Σ_p χ₅(p)/√p 的字符振荡有界性、并集 vs 单族余项包络与 L(χ₅) 主项修正

摘要：本工作把 Fourier 剖面发现的'并集素项净压制'翻译为显式公式余项上界的定量估计。结论（数值+结构）：（1）Σ_p χ₅(p)/√p（σ=1/2 临界）部分和**振荡有界**：sup|部分和|≤2.46（X=5×10⁶），Σ_p χ₅(p)/(√p log p) 有界 ~1.85——χ₅ 的字符振荡消去，跨族项不产生长周期漂移；（2）并集素项包络（分段 sup，Σ a_p/(√p log p)）在**全尺度严格小于单族**：比值 0.57/0.71/0.82/0.90/0.94（X 分段 10²–5×10⁶），收益随 X 衰减；（3）但**均方口径并集 1.263× 单族**（Σ(1+χ)²/p=3.457 vs Σ1/p=2.736，X=2×10⁶）——(1+χ)²=4·1_{χ=+1}，χ₅=−1 处 0×、+1 处 4×，净效应并集功率更大，二矩论证无增益（呼应攻防 XVI 白噪声判定）；（4）**在线比例余项数值级**：密度侧 sup|S_K|/(π·(T/2π)λ)≈8.1×10⁻⁶，配对侧 ∫dF≈−0.0094≈0，综合 0.6725−O(10⁻⁵~10⁻³)——余项不构成阻碍，常数 0.6725 本身是上限；（5）**L(χ₅) 主项修正**：N_L(T)=(T/2π)[log(T/2π)+log 5−1]+O(log qT)（Γ(s/2) 相位，χ₅(−1)=+1），ζ 口径 D(t)≈0 完美验证，L 数据含 ~0.27% R-S 求根系统伪影（趋势 −0.0052/单位，已披露）。

关键词：并集素项；χ₅ 字符和；S(t) 余项；在线比例；L(χ₅) 主项；Riemann–von Mangoldt

# 1 结论

（1）**Σ_p χ₅(p)/√p 振荡有界**：临界指数 σ=1/2 处部分和 sup≤2.457（X=5×10⁶，终值 −2.433）；σ=0.6（绝对收敛区）终值 −1.823；S(t) 素项口径 Σ_p χ₅(p)/(√p log p) sup≈1.85。字符和 O(√x) 类的振荡消去成立——**跨族素项不产生长周期漂移**，超低频零负债得到理论解释。

（2）**并集素项包络全尺度压制（sup 口径）**：分段 sup（Σ a_p/(√p log p)，a=1 单族 / a=1+χ₅ 并集）：比值 0.57/0.71/0.82/0.90/0.94——χ₅=−1 素项（含最大幅度项 p=2,3）消失的收益在每个素数区间都成立，收益随 X 衰减（χ₅=±1 渐近各半 ⟹ 大 X 趋 1）。

（3）**均方口径并集 1.263× 单族**：(1+χ₅(p))²=4·1_{χ₅=+1}——χ₅=−1 处 0×、+1 处 4×，净效应并集功率更大。**'净压制'只在幅度 sup 层成立，功率层不成立**；这与攻防 XVI 二阶矩'近对角白噪声'判定一致。

（4）**在线比例余项数值级**：密度侧 sup|S_K|/(π·(T/2π)λ)=28.1/(π×1.095×10⁶)≈8.1×10⁻⁶（并集；单族 29.9 给 8.7×10⁻⁶）；配对侧 ∫dF≈−0.0094≈0（攻防 XVII）。综合：在线比例 ≥0.6725−O(10⁻⁵~10⁻³)（T=6×10⁵ 有限口径）——**余项不构成阻碍，上限是常数 0.6725 本身**。

（5）**L(χ₅) 主项修正**：零点计数主项 N_L(T)=(T/2π)[log(T/2π)+log 5−1]+O(log qT)（此前误用 log(5/π) 或 ζ 口径缺 log q 项）；ζ 口径 D(t)=N−主项≈0 完美验证；L 数据含 ~0.27% R-S 求根系统伪影（趋势 −0.0052/单位），S_L 的 max/RMS 含此伪影，仅作披露参照。

# 2 机制重建：显式公式余项与 χ₅ 符号调制

## 2.1 S(t) 的素项展开

零点计数 N(t)=主项+S(t)。对 ζ：N_ζ(t)=(t/2π)[log(t/2π)−1]+7/8+S_ζ(t)+O(1/t)；对 L(s,χ₅)（primitive 偶实字符，q=5）：

N_L(t)=(t/2π)[log(t/2π)+log 5−1]+O(log 5t)+S_L(t)。

Backlund 函数 S(t)=(1/π)arg L(1/2+it) 的素项展开（显式公式）：

S_ζ(t)=−(1/π)Σ_p sin(t log p)/(p^{1/2}log p)−(1/π)Σ_{p^m,m≥2}…；S_L(t)=−(1/π)Σ_p χ₅(p)sin(t log p)/(p^{1/2}log p)−…

并集：S_K(t)=S_ζ(t)+S_L(t)，素项主行 = −(1/π)Σ_p (1+χ₅(p)) sin(t log p)/(p^{1/2} log p)。密度偏差 ε(t)=S′(t) 的素项 = −(1/π)Σ_p (1+χ₅(p))cos(t log p)/p^{1/2}——Fourier 剖面检测的正是 cos 基的周期图。

## 2.2 χ₅ 符号分解与均方结构

关键代数：(1+χ₅(p))²=4·1_{χ₅(p)=+1}+1_{p=5}（χ₅=−1 处 0×、+1 处 4×、p=5 处 1×）。均方口径：

E|ε_K|² ∝ Σ_p (1+χ₅(p))²/p = 4Σ_{χ₅=+1}1/p+1/5；E|ε_ζ|² ∝ Σ_p 1/p。

X=2×10⁶：Σ(1+χ)²/p=3.457 vs Σ1/p=2.736，比值 1.263（大 X 极限 →2，因 χ₅=±1 各半密度时 4×(1/2)=2）。**均方层面并集>单族**——Fourier 剖面里 χ₅=−1 的'精确对消'是逐素数点的（sup 层），功率层被 +1 增强主导。

## 2.3 Levinson 余项分解

在线比例 ≥0.6725−余项/(2(T/2π)λ)。余项 = 密度侧（S_K 的 sup/RMS，控制计数对主项的偏离）+配对侧（ΣK² 相对理论 C_MT^K 的偏差，攻防 XVI/XVII 已测 ∫dF≈−0.0094）。本轮量化密度侧。

# 4 L(χ₅) 主项修正与数据伪影

## 4.1 主项修正（理论）

L(s,χ₅) 的完备函数 Λ(s,χ₅)=(q/π)^{s/2}Γ(s/2)L(s,χ₅)（χ₅(−1)=(4/5)=+1 偶 ⟹ a=0，Γ 因子 Γ(s/2)）。相位：

θ_L(t)=Im[((1/2+it)/2)log(q/π)]+Im log Γ(1/4+it/2)=(t/2)log(q·t/2π)−t/2−π/8+O(1/t)，

故 N_L(t)=(1/π)θ_L(t)+1+O(1/t)=(t/2π)[log(t/2π)+log q−1]+O(log qt)——**log q=log 5 是线性项，来自 (t/2)log(q/π) 的 (t/2)log q 部分**。此前（历史脚本）对 L 误用 ζ 口径 (t/2π)(log(t/2π)−1)（缺 log q）或 log(5/π)（错，缺 (t/2π)log π 补偿），均产生 ~10⁵ 级伪主项（C_L≈75098 / 52911）。修正后 C_L=−1744（含数据伪影）。

## 4.2 数据伪影披露

L 零点序列由 R-S 主项求根（ZL_one 扫描）生成，实测计数相对理论主项有 ~0.27% 系统负偏差（趋势 −0.0052/单位，T=6×10⁵ 处累计 −3147 个）。该偏差**不影响**本轮 A/补测结论（纯素数表，独立于零点数据）；但对 S_L(t) 的 max/RMS（max|S_L|≈1744、RMS≈878）含此趋势伪影，不能作为真实 Backlund 函数界。密度偏差 ε(t)（差分）自动消除常数与线性趋势，Fourier 剖面结论不受影响。

# 5 战场判定

（1）**'并集素项净压制'是真的，口径受限**：sup 口径全尺度成立（0.57–0.94），χ₅ 字符和有界（≤2.46）⟹ 无长周期漂移；均方口径并集 1.26–2×单族——**Levinson 二矩类论证在并集上无增益**（与攻防 XVI 白噪声判定闭环）。

（2）**在线比例桥余项不阻碍**：密度侧 8.1×10⁻⁶、配对侧 ≈0，综合 0.6725−O(10⁻⁵~10⁻³)。推进 7/8（0.875）需要的是**常数层突破**（0.6725→更高），而攻防 XVIII 已判 Q(0) 入口恒非正——**余项级证实：缺口在常数不在余项**。

（3）**下一步方向**：①把 sup 包络压制的 X 衰减与大 X 极限的均方 2× 合并为 S_K(t) 的显式界（Montgomery–Taylor 型小偏差估计）；②L4 交叉项（S_ζL 估计）独立文档已备，与本次密度余项合并给出在线桥的完整余项链。

# 6 诚实边界

（1）部分和 sup 是数值上界（X≤5×10⁶），非解析证明：Σ_p χ₅(p)/√p 的 O(log² X) 型上界需字符和显式公式（Pólya–Vinogradov 型）支撑，未在本文给出。

（2）均方比值 1.263 有 X 依赖：大 X 极限趋 2（χ₅=±1 各半密度）；分段 sup 比值趋 1。'压制'是有限 X 的净效应。

（3）L 零点数据的 0.27% R-S 伪影使 S_L 的绝对值不可信（max/RMS 仅披露参照）；差分口径（ε、Fourier）免疫。

（4）在线比例 0.6725−O(10⁻⁵~10⁻³) 是数值级估计，Levinson 理论余项界 O(1/√log T)≈0.27 未改进——数值与理论界的差距提示配对结构特殊或上界非紧，未在此判定。
