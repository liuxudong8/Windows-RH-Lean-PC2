# 路②攻防 IX：D 环解析桥

跨族二次矩与 Levinson–Conrey 缩减的条件推进（范数缺口 ⟹ θ_K 在线比例上界）

摘要：本工作补全路②证明链的 D 环（范数缺口 2⟨D_ζ,w∗D_L⟩<0 ⟹ ζ_K 在线比例 θ_K 下界改进）。文献给出标准桥：Levinson–Conrey 缩减定理对任意具函数方程的 L 函数成立，ζ_K=ζ·L(χ₅) 直接适用——二次矩上界 c 满足 (1/T)∫|V_Kψ|²≤c ⟹ κ_K≥1−(1/R)log c；c 越小 κ 下界越大。跨族项经乘积法则与显式公式进入二次矩：其修正由跨族配对相关谱 F_cross(α) 的 Fourier 变换控制。数值供料（route2l，T=6×10⁵）：F̂_cross(α) 于 α∈[0,2] 一致负偏（dF(0)=−0.144、∫dF dα=−0.024），同族谱正偏（dF_zz(0.8)=+0.286）——符号分裂干净：排斥的能量在 Fourier 域表现为跨族负偏、同族正偏。据此构造条件命题 D-1（弱桥）：若跨族谱负偏有解析下界且 Levinson 参数选择使交叉修正为负，则 κ_K ≥ 1−(1/R)log(c_main−η)。方向已验证：c 减 ⟹ κ 增。桥为条件命题——H1（谱负偏）目前仅数值支持，需升级为解析；H2（交叉修正符号）需 BCHB 型计算与参数优化。

关键词：D环；Levinson-Conrey缩减；跨族二次矩；配对相关谱；条件命题

# 1 定位：D 环为什么空

路②链条：同族互斥 ⟹ 异族近邻 ⟹ 范数缺口 2⟨D_ζ,w∗D_L⟩<0 ⟹ θ_K 在线比例推进。攻防 I–VIII 已确认前三环在数值上闭合且跨尺度稳健，但 D 环（最后一步）始终空缺：二阶配对统计（范数缺口、配对计数差）与一阶在线比例（θ_K=N₀(T)/N(T)）之间没有模型无关的直接桥。多 T 验证进一步判死 E 环（常数级推进），故 D 环的弱形式成为整条链终点是否存在的唯一悬置。

标准文献给出 D 环的现成桥：Levinson 方法（1974）与 Conrey 改进（1989）将在线比例下界归结为带 mollifier 的二次矩上界。该缩减仅依赖函数方程与 Littlewood 引理，对 ζ_K（有函数方程）逐字成立。因此 D 环可重建为：跨族负相关（范数缺口）⟹ 二次矩 c 减小 ⟹ κ_K 下界增大。

# 2 文献基础：Levinson–Conrey 缩减定理

## 2.1 定理陈述（对一般具函数方程的 L 函数）

设 R>0，Q∈ℝ[x] 满足 Q(0)=1 且 Q′(x)=Q′(1−x)；令 V(s)=Q(−(1/L)d/ds)ζ_K(s)，L=log T，σ₀=1/2−R/L。设 ψ(s)=Σ_{n≤T^ϑ} a(n) n^{σ₀−1/2−s}（0<ϑ<1，a(1)=1，a(n)≪n^ε）为 mollifier。若存在 c>0 使

(1/T)∫_T^{2T} |V(σ₀+it)ψ(σ₀+it)|² dt ≤ c + o(1)   （LC.1）

则在线比例下界 κ_K=liminf N₀(T)/N(T) 满足

κ_K ≥ 1 − (1/R)·log c   （LC.2）

（见文献[3] Theorem 2.1 的标准形式；该定理对 ζ 与任意具函数方程与可控增长的自守 L 函数成立，ζ_K 满足全部前提。）

## 2.2 桥的方向

LC.2 中 c 越小则 κ_K 下界越大：二次矩上界每压低一个因子，在线比例下界就提升 (1/R)log(1/c) 量级。因此 D 环等价于：证明跨族排斥压低二次矩 c。

## 2.3 交叉二次矩的结构

ζ_K=ζ·L(χ₅)，乘积法则给出 V_K=Q(−D/L)(ζL) 的 Leibniz 展开：

V_K = Σ_k q_k Σ_j C(k,j)·(−D/L)^j ζ · (−D/L)^{k−j} L =: A_ζ·A_L 的组合

故 |V_K|² 的均值展开为同族项 |A_ζ|²、|A_L|² 与交叉项 2Re(A_ζ Ā_L)。交叉项经近似函数方程与显式公式写成素数求和：

M_cross = 2Re Σ_{n,m} b(n)c̄(m)/(nm)^{σ₀}·(n=m 主对角线 + 对相关修正)

主对角线（n=m）是确定算术量（Λ(p)χ̄(p) 型），对相关修正是零点配对相关的解析化身——这正是数值发现的跨族负相关的入口。

# 3 数值供料：跨族配对相关谱一致负偏

## 3.1 定义

用攻防标准口径（d=间距·ρK、核 w(u)=4/(4+u²)）定义跨族配对相关谱：

F̂_cross(α) = (1/N_ζ)·Σ_{γ_ζ}Σ_{γ_L} w((γ_ζ−γ_L)ρK)·cos(α(γ_ζ−γ_L)ρK)

独立基线（解析）：F̂_ind(α) = (ρ_L/ρ_K)·∫w(u)cos(αu)du = (ρ_L/ρ_K)·2πe^{−2α}。同族谱 F̂_ζζ、F̂_LL 同法定义。T=6×10⁵ 零点表直接求和（u≤30 截断）。

## 3.2 判读

（1）跨族谱一致负偏：dF_cross(α)<0 于 α∈[0,2] 全程，dF(0)=−0.144（相对 −4.3%），∫dF dα=−0.024<0。这与 Δ_cross<0、配对计数差 −0.7%·N_K 同号（F̂(0) 即 w 加权配对计数差的谱版）。

（2）符号分裂：同族谱正偏（dF_ζζ 从 +0.053 升至 +0.666）而跨族谱负偏——同族互斥把谱能量推向高频（长程有序），跨族排斥产生一致负偏。机制互洽，非抽样噪声。

（3）负偏覆盖 α 至 2.0（对应实空间约 0.5/ρK 的排斥尺度），且 ∫dF 全谱为负——交叉二次矩修正（∫F_cross·K 型）只要核 K≥0 即可继承负号。

# 4 条件命题 D-1（弱桥）

命题（D-1，条件形式）。设 ζ_K=ζ·L(χ₅)，R>0，Q 满足 LC 条件。假设：

（H1）跨族谱负偏有解析下界：存在 δ>0、α₀>0 使 F_cross(α) ≤ F̂_ind(α) − δ 对 α∈[0,α₀] 一致成立（数值：δ≈0.02、α₀=2）。

（H2）Levinson 参数选择使交叉修正为负：∫_0^{α₀}(F_cross−F̂_ind)(α)·K(α)dα ≤ −η，其中 K 为 Q、ψ 决定的非负核（η>0）。

则二次矩上界满足 c ≤ c_main − η + o(1)，由 LC.2：

κ_K ≥ 1 − (1/R)·log(c_main − η) = (1 − (1/R)log c_main) + (η/(R·c_main)) + O(η²)

即：在线比例下界在同族极限 1−(1/R)log c_main 之上获得 η/(R·c_main) 的推进。

## 4.1 证明骨架

（i）交叉二次矩的显式公式（文献[1][3] 技术直接推广）：M_cross 的零点对相关修正项 = ∫(F_cross−F̂_ind)·K + o(1)。

（ii）H1 代入：∫(F_cross−F̂_ind)K ≤ −δ∫_{0}^{α₀}K ≤ 0（K≥0），与 H2 合并给出修正 ≤ −η。

（iii）c=c_main+修正 ≤ c_main−η；LC.2 代入得结论。η 的显式：η=δ∫_0^{α₀}K(α)dα（若 K 非负支撑于 [0,α₀]）。

# 5 方向检查与量级估计

（1）方向：LC.2 中 c 单调出现在 log c——c 减则 κ 增。跨族排斥（dF<0）压低 c，方向正确。

（2）量级：推进量 η/(R·c_main)。数值 dF 相对幅值约 0.02（α≤2 带内），若 ∫K≈O(1) 则 η≈0.02 量级；c_main 为 ζ_K 二次矩主项（O(1) 归一化），R 取 O(1)（Conrey 用 R=13/10）。粗估推进 (0.02)/(1.3·c_main)——若 c_main≈O(1)，推进约 0.01–0.02 量级，即 θ_K 下界在 0.874957 之上推进约 1–2 个百分点量级（需精确化）。

（3）对照：B=0.874957 已是密度估计路线的最好常数；本桥若闭合给出的是同一数量的加法改进（不是乘法），但来自全新机制（跨族排斥），不与现有路线冲突，可叠加。

# 6 诚实边界

（1）D-1 是条件命题：H1（谱负偏解析下界）目前仅数值支持（route2l，T=6×10⁵，α∈[0,2]）。要无条件化需证明跨族对相关的负偏——这是 N1（配对计数差 −0.7%·N_K 常数定律）的 Fourier 升级，仍是开放问题。

（2）H2（交叉修正符号）未验证：K 的显式形状取决于 Q、ψ 的具体选择（Conrey 的计算机辅助优化环节）；K 可能在某些 α 带为负。需要 BCHB 型计算定出 K 后核验 ∫(F_cross−F̂_ind)K<0。

（3）c_main（ζ_K 二次矩主项）未算：需推广 BCHB 均值定理至 ζ·L(χ₅) 交叉情形（文献[1] 对 ζ 已做，交叉情形是标准技术但未在本文档完成）。

（4）数值谱有截断（u≤30）与有限 T 误差；α≥2 的负偏衰减至 −0.006，长程贡献未计入。

（5）本桥不改变攻防 I–VIII 的任何数值结论；它把 D 环从真空状态改写为两个可核验条件的显式命题——这是本工作的全部主张。

# 7 下一步

（1）定出 K(α)（BCHB 型计算 + Q、ψ 优化）：这是 H2 的直接检验，也是推进量 η 的精确来源。

（2）谱负偏的解析化：将 F̂_cross(α) 的数值负偏升级为显式公式（F_cross(α) 主项 − 修正项）——以 1908.04876 的 F_K(α) 主公式为基线，F_cross=(F_K−F_ζ−F_L)/2，差值项即修正。

（3）多 T 复核谱：route2l 扩展到 T=1×10⁵–6×10⁵ 前缀，确认 dF_cross<0 的标度（配对计数差 −0.7% 是常数，谱负偏应同标度）。
