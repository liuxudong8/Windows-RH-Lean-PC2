# 3　B2：无 Siegel 验证

Siegel 零点威胁：若 L(χ₅) 有实零点 β 靠近 1（β≥1−c/logT），则大量零点可被吸到实轴附近，零密度 δ* 全部失效。实二次域 Dirichlet 类数公式[7]给出闭式：

L(1, χ₅) = 2h·log ε/(w·√D) = 2·log φ/√5 = 0.430408940964（h=1，w=1，ε=φ=(1+√5)/2）。	（2）

# 7　左尾 224 待审项

ĥ<3 的 224 个异常峰集中在 ζ 族（216）而非 L 族（8）——与攻防 XIX「0.27% R-S 伪影在 L 族」的预期方向相反。两种假说：(a) ζ 族 R-S 求根同样存在伪影（假零点处无真实峰⟹ĥ≈背景≈0）；(b) 背景大负涨落的重尾（46 个 ĥ<1 超出高斯预期约 3 个量级，分布非高斯）。审计路线：对 ĥ<3 的 224 个零点逐一核邻域素数项背景与邻峰结构、对照攻防 XIX 的伪影定位清单。此项不阻塞本攻防判定（无论假说成立，异常占比 1.0×10⁻⁴ 不影响 N_off 上界两个量级的余量），列为待审。

# 8　诚实边界与未决

① 零密度主幂口径忽略 log 因子与常数——log⁵ 保守口径在 T=6×10⁵ 完全无约束（δ=0.4 时 frac 仍 14.6），无条件闭合依赖 Ingham 常数的具体估计，须在正式化时补齐。② 峰高口径是数值排除而非证明：它依赖零点数据正确性（R-S 伪影已被左尾审计量化到 1.0×10⁻⁴）与基线模型可预测性。③ 盲区 δ<0.05 的理论威胁（>21.9 万「极浅且极多」离线）只能靠三条路线压缩：Bourgain 型现代零密度界压 δ*、更大 T（≥6×10⁷）压 log 因子、或密度剖面理论（N(1/2−δ,T) 在 δ→0 的精细结构）——均超出本攻防数值工具范围。④ B4 未存左尾零点的位置明细（复算需 ~40 分钟），与第 7 节待审项共用此缺口。

# 9　判定总结

入口 B 四件套数值定向完成并落档：零密度给出无条件段 δ≥0.0902；无 Siegel 验证堵死近实轴漏（D=5 无条件）；窗口法证明威胁窗 δ∈[0.05,0.09] 完全可检测；全区间实测给出 δ≥0.05 离线 ≤2139（2σ）/3208（3σ）——比目标带低约 100 倍。主线「常数→θ_K 推进」的最后一公里状态：威胁窗数值闭合，盲区收缩至 δ<0.05 的单一窗口，θ_K≥7/8 的等价式在数值侧仅剩该盲区内的理论威胁。下一步候选：左尾 224 审计（~40 分钟复算）、Bourgain 型零密度理论、或更大 T 采样。
